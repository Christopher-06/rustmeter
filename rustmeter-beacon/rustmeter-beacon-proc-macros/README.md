# RustMeter Beacon Proc Macros

**Internal procedural macros for [RustMeter Beacon](https://crates.io/crates/rustmeter-beacon).**

This crate defines the procedural macros (like `#[monitor_fn]`) utilized by the RustMeter tracing system. **It is not meant to be used directly by end-users.** 

Please use the main `rustmeter-beacon` crate to instrument your applications.

👉 **[Learn more in the RustMeter Book](https://christopher-06.github.io/rustmeter/)**
