# RustMeter Beacon Core

**Internal core library for [RustMeter Beacon](https://crates.io/crates/rustmeter-beacon).**

This crate houses the foundational types, data structures, and logic for RustMeter's embedded instrumentation. **It is not meant to be used directly by end-users.** 

Please use the main `rustmeter-beacon` crate to instrument your applications.

👉 **[Learn more in the RustMeter Book](https://christopher-06.github.io/rustmeter/)**
